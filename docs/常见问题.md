# 常见问题

> 💡 **遇到问题先看「状态行」**——就是面板最下面那一行小字。
> 它基本上会直接告诉你出了什么事。**90% 的问题看它就能解决。**

## 1. 面板看不见

- **现象**：点了「打开悬浮面板」，回到桌面或游戏，屏幕上什么都没有，也没任何提示。
- **原因**：**悬浮窗权限被重置了。** 最常见的是**重新安装**过 App（比如覆盖安装），Android 会把这个权限清掉。
- **怎么办**：
  1. 打开「预算修改器」App，点 **「打开悬浮面板」**。
  2. 如果没权限，App 会**自动跳到授权页面**，把「显示在其他应用上层」开关打开。
  3. 没自动跳的话，手动去：**设置 → 应用设置 → 应用管理 → 预算修改器 → 权限管理 → 显示在其他应用上层 → 允许**。
  4. 回 App 再点一次「打开悬浮面板」。
  5. MIUI 用户还不行的话，再去把 **「后台弹出界面」** 也允许。

> 有电脑的话，一条命令搞定：
> `adb shell appops set com.pbmod.budget SYSTEM_ALERT_WINDOW allow`

## 2. 状态一直停在「准备中…」

- **现象**：面板出来了，但状态行一直显示 `准备中…`，点「应用」也没反应。
- **原因**：面板在后台申请 **root 权限**（会弹 Magisk 授权窗）时**卡住了**——通常是 Magisk 弹了窗但**没点允许**，或者根本没注意到有弹窗。
- **怎么办**：
  1. 回到桌面 / 下拉通知栏，看看有没有 **Magisk 的授权弹窗**，点**允许**。
  2. 弹窗已经消失了的话：打开 **Magisk → 超级用户**，找到「预算修改器」，把开关打开。
  3. 回到面板，点一下「检测」或「应用」重试。
  4. 面板有超时保护，超时后会显示 `超时: root 可能没有授权`。

> 想确认 root 是否正常，可以用电脑执行：`adb shell su -c id`
> 正常应该输出 `uid=0(root)`。

## 3. 提示「超时: root 可能没有授权」

- **现象**：等一会儿之后，状态行变成 `超时: root 可能没有授权`。
- **原因**：**Magisk 授权没通过**。可能是弹窗没人理（自动超时），也可能是之前在 Magisk 里点了「拒绝」，或者手机根本没 root 好。
- **怎么办**：
  1. 打开 **Magisk → 超级用户**，检查「预算修改器」是不是被**拒绝**了；是的话改成**允许**。
  2. 顺便看看 Magisk 里的「超级用户」列表里有没有它，没有就在面板上重新点一次「应用」触发申请。
  3. 确认手机 root 本身正常（别的 App 能用 root 吗？）。
  4. 都正常还超时，就把面板关掉重开一次，或者重启手机再试。

## 4. 提示「没有找到 X (0 处)」

- **现象**：点「应用」后显示 `没有找到 10000 (0 处)。请照抄屏幕上现在的预算再试`。
- **原因**：**「当前」那个数字填错了。** 最常见的是——你填成了屏幕**顶部绿色的「已经花掉的钱」**，而不是它**下面** `预算:` 后面的数字。
- **怎么办**：
  1. 切回游戏，抬头看清楚 `预算:` 后面**到底是多少**。
  2. 回面板，点 **「当前:」**，按 **`清空`**，重新照着输入。
  3. 再点「应用」。

> ⚠️ **这是新手最常踩的坑。** 记住：上面绿的是**花的钱**，下面那行 `预算:` 才是**预算**。
> 填错了不会弄坏任何东西，重填就行。

## 5. 提示「替换 N 处, M 处写入失败」

- **现象**：状态行显示 `替换 46 处, 3 处写入失败, 建议再点一次`。
- **原因**：**这是正常的，不是出错。** 游戏一直在运行，内存里的数字随时在变；有极少数几处刚好在你写入的一瞬间被游戏改掉了（比如正在自动保存）。
- **怎么办**：
  1. **直接再点一次「应用」** 就行，一般第二次就全成功。
  2. 如果反复失败：回到游戏**站着别动**（不要建造、不要切关卡、不要暂停），再点「应用」。

## 6. 提示「已完成」但游戏里预算还是旧的

- **现象**：状态行明明说 `已完成: 46 处 -> 999999`，可游戏上方还是 `预算: $10,000`。
- **原因**：**这是正常现象，不是 bug。** 游戏只会在**你自己动手建造或删除**的时候才重画那行字。工具改的是内存，游戏并不知道要刷新界面。
- **怎么办**：
  1. 切回游戏。
  2. **放上一块材料，或者点选一块材料然后把它删掉。**
  3. 那行 `预算:` 立刻就会变成新数字。

> 这一步**必须做**，详见 [使用方法 第四节第 6 步](使用方法.md)。

## 7. 提示「游戏没在运行, 请先打开游戏并进入关卡」

- **现象**：点「应用」或「检测」时出现这句话。
- **原因**：找不到游戏进程。要么游戏**根本没开**，要么游戏开在**主菜单 / 关卡选择界面**，**还没进关卡**。
- **怎么办**：
  1. 打开游戏。
  2. **一定要进到一个关卡里面**——就是能看到桥、能看到上方 `预算: $10,000` 的那个画面。
  3. 回到面板再点一次。

> 为什么必须在关卡里？因为预算这个数字是**关卡加载时**才被创建出来的，在主菜单里它压根不存在。

## 8. 面板挡住了游戏

- **现象**：面板太大，把桥挡住了，没法造桥。
- **原因**：面板处于完整展开状态。
- **怎么办**：
  1. **点一下标题栏**（点「预算修改器」这几个字，或标题栏上的 **「—」**）。
  2. 面板立刻收成一条细标题栏（只有 113 像素高），就不挡了。
  3. 想改数字时**再点一下标题栏**就恢复——**输入的数字不会丢**。

> 也可以**按住标题栏拖动**，把面板挪到屏幕角落。

## 9. 面板被拖到屏幕边上，找不回来

- **现象**：手滑把面板拖到屏幕边缘，好像跑到屏幕外面去了。
- **原因**：拖动是允许的。**不过现在已经加了边界限制**，最多只能拖出去一点点，**不会完全消失**。
- **怎么办**：
  1. 先看屏幕**四个角落和边缘**，那条细长的标题栏通常还在。
  2. 找到后按住标题栏把它拖回来。
  3. 实在找不到：打开「预算修改器」App → 点 **「关闭悬浮面板」** → 再点 **「打开悬浮面板」**，面板会**回到左上角默认位置**。

## 10. 游戏里显示「预算: 无限」

- **现象**：游戏上方显示 `预算: 无限`，改也改不动。
- **原因**：两种情况——
  - 你在**教学关**里，教学关的预算本来就是无限的；
  - 或者这关的预算数值是 0，游戏会把**小于等于 0** 的预算一律显示成「无限」。
- **怎么办**：
  1. 确认自己进的是**正式关卡**，不是教学关。
  2. 确实是正式关卡却显示「无限」，说明这关本身就不限预算，不用改。
  3. 想试试工具好不好用，随便找个正常关卡（前几关就行）。

## 11. 用这个会不会被封号？安全吗？

- **现象**：担心被游戏封号，或者怕弄坏手机。
- **原因**：先解释一下原理——这个工具只是**在你自己的手机内存里，把那个预算数字换成别的数字**。
- **结论**：
  - ✅ **纯本地操作**：App **不联网**，不会向任何服务器发送任何数据。
  - ✅ **不改存档**：游戏存档文件一个字节都不动，**退出游戏就恢复原样**。
  - ✅ **单机游戏**：Poly Bridge 是纯单机游戏，没有联机对战，不存在影响别人的问题。
  - ⚠️ **需要 root**：root 本身有一定风险，请确认你知道自己在做什么。

> 简单说：**风险很低**，但手机 root 带来的风险请自行承担。

## 12. 支持哪些游戏版本和手机？

- **现象**：想知道自己的手机能不能用。
- **原因**：工具是直接读写游戏内存的，所以**游戏版本**会影响兼容性。
- **怎么办**：
  - 实测通过的游戏版本：**Poly Bridge v1.2.3**（Android 版，包名 `com.drycactus.hq.polybridge`）。
  - 实测通过的手机：**Redmi K40（M2012K10C）、Android 13、MIUI**。
  - 其他版本 / 机型**可能**能用，但**没测过，不保证**。
  - 硬性要求：**必须 root**、**Android 8.0 以上**。

> 游戏更新后，如果预算的位置变了，工具可能就找不到那个数字了（会提示「没有找到 …(0 处)」）。
> 遇到这种情况，说明需要针对新版本重新适配。

## 13. 能解锁关卡吗？

- **现象**：想直接解锁后面的关卡，跳过前面的。
- **原因**：**不能，这是特意不做的。** 本工具**只改预算**，不碰关卡解锁状态。
- **怎么办**：
  - 就是不解锁，请自己正常通关。
  - 工具不会改关卡解锁、不会改星星数量、不会改存档里的任何进度。

## 14. 数字输不进去 / 键盘没反应

- **现象**：点键盘上的数字，按钮没反应，「当前:」或「改成:」还是「—」。
- **原因**：**你还没选中要填哪个框。** 键盘只会往「当前」或「改成」里输入，必须先点一下那个按钮。
- **怎么办**：
  1. 先点 **「当前:」** 或 **「改成:」**，让它**变成绿色**（绿色＝正在编辑这个框）。
  2. 再点键盘上的数字。
  3. 如果还是不动，检查一下是不是已经输满 10 位数字了。

## 15. 提示「两个数字都要填, 大于 0 且不超过 20 亿」

- **现象**：点「应用」时出现这句话。
- **原因**：输入的数字不合法。
- **怎么办**：
  - **不能留空**：「当前」和「改成」两个都要填。
  - **不能是 0 或负数**：必须大于 0。
  - **不能太大**：最大 2000000000（20 亿），最多 10 位数字。

> 一般玩家改成几十万、几百万就完全够用了。

---

## 16. 重启游戏后修改就没了

- **现象**：昨天改好的预算，今天开游戏又变回原样了。
- **原因**：**这是设计如此。** 修改只存在**运行内存**里，**不写进存档**。
- **怎么办**：
  1. 这是正常的，**重新改一次**就行。
  2. 每进一个新关卡按 [使用方法](使用方法.md) 走一遍，只要 10 秒钟。

> 好处是：随时想恢复原版难度，退出游戏重进就可以了。

## 17. 点了「✕」之后面板再也调不出来

- **现象**：点了面板上的 ✕，面板消失了，不知道怎么弄回来。
- **原因**：**「✕」是彻底关闭面板**（不是最小化）。关闭后后台服务还在，但那个悬浮窗被移除了。
- **怎么办**：
  1. 打开 **「预算修改器」** App。
  2. 点 **「打开悬浮面板」**。
  3. 面板就回来了。

> 如果你只是**不想让面板挡游戏**，应该点 **「—」**（最小化），而不是 **「✕」**。

## 18. 怎么彻底卸载干净

- **现象**：不想用了，想删干净。
- **原因**：App 会在手机里放一个临时的小助手程序。
- **怎么办**：
  1. 打开面板点 **「✕」** 关闭面板（或打开 App 停止服务）。
  2. 到系统「设置 → 应用管理」里正常卸载「预算修改器」。
  3. 想连临时文件一起清理（需要电脑 + adb）：

     ```
     adb shell su -c "rm -f /data/local/tmp/pbmem"
     ```
  4. 搞定。游戏本身不受任何影响。

## 还是不行？

把**状态行显示的那句话**（或者截图）发出来，一般一眼就能看出问题。

按这个顺序排查，基本都能解决：

1. **面板根本看不见？** → 去设置里给「显示在其他应用上层」权限（[第 1 条](#1-面板看不见)）。
2. **看得见但一直「准备中…」？** → 去 Magisk 里允许 root 授权（[第 2 条](#2-状态一直停在准备中)）。
3. **点了「应用」说没找到？** → 数字填成了绿色已花费金额，重填（[第 4 条](#4-提示没有找到-x-0-处)）。
4. **说「已完成」但数字没变？** → 忘了回游戏放/删一块材料（[第 6 条](#6-提示已完成但游戏里预算还是旧的)）。

常见原因排下来无非三种：**没有悬浮窗权限**、**Magisk 没授权 root**、**数字填成了已花费金额**。
