# 游戏本体版本信息

本仓库**不包含游戏本体**（版权归原厂所有）。本文记录修改器所适配的那个版本的完整信息，
方便你确认自己装的是不是同一个版本。

> ⚠️ **版本对不上，修改器可能失效。** 预算数值在内存里的布局由 IL 决定，
> 换一个版本（尤其是官方原版）字段结构可能完全不同，扫描就找不到。

### 校验值

```text
SHA-256  BABF9FD7815AE37210EABEBB8985329960E0ABBA60E04B2F8D832D5927E7918D
MD5      F350C88CE36296BFB11C9FF70FAD8573
```

### 怎么自己校验

Windows（PowerShell）：

```powershell
Get-FileHash .\PolyBridge_1.2.3_原版游戏.apk -Algorithm SHA256
```

手机（Termux）或 Linux：

```sh
sha256sum PolyBridge_1.2.3_原版游戏.apk
md5sum   PolyBridge_1.2.3_原版游戏.apk
```

**哈希对得上 = 同一个版本，修改器可以直接用。**

## 几点说明

- 本仓库**只分发自制修改器和文档**，不含游戏本体；下载链接指向第三方网盘。
- 游戏版权归原厂所有，**请自行确认你的获取方式合法**。
- 修改器**只适配上面这个版本**。如果你装的是官方原版（包名不同），
  预算字段的布局可能完全不一样，扫描会找不到数值。
- 观察记录：这个 APK 的应用名是「Poly Bridge 2-Bridge Master」、包名中带 `hq` 段、
  `compileSdkVersion` 为 23 而 `targetSdkVersion` 为 28 —— 从特征上看像是
  **第三方重新打包的版本**，与 Dry Cactus 官方在 Google Play 上架的版本不一定一致。
  如果你的机器上装的是官方版，请先确认包名是否也是 `com.drycactus.hq.polybridge`。

## 修改器的要求（与本文件配套）

装好游戏之后：

1. 手机需要 **root（Magisk）**。
2. 打开游戏并**进入关卡**，确认屏幕上方出现 `预算: $xxxx`。
3. 打开修改器 → 「打开悬浮面板」→ 按 [`使用方法.md`](使用方法.md) 操作。

如果状态行一直提示 `没有找到 X (0 处)`，通常不是版本问题，而是把绿色那个
「已经花掉的钱」当成了预算 —— 要填它**下面** `预算:` 后面那个数字。
